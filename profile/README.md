## Getting Started in 5 Steps

1. **Install and launch.** Open pacifist mac download (the current release is version 4.1.4). The
   opening window offers to open a package, open the system-wide installer contents, or verify what's
   already installed — start with "Open Package."

2. **Point it at your package.** Choose the .pkg or .dmg you want to open, or drag it onto the window.
   As a package installer mac tool, Pacifist reads the file without running it, so nothing is installed
   just because you opened it.

3. **Browse the contents.** The package expands into a familiar folder tree showing every file it
   would place on your system, with sizes and destinations. Click through to find the exact item you're
   after — an app, a framework, a font, a single resource.

4. **Extract just what you need.** Select the file or folder and choose Extract To, then pick a
   destination. This is the whole point of a pkg extractor mac workflow: you retrieve one piece instead
   of rerunning an entire installer. Choose Install instead if you want Pacifist to put it back in its
   original location.

5. **Verify installed files (optional).** Use "Verify Installed Files" to compare what's on your Mac
   against the original package. download pacifist for mac flags anything missing, modified or damaged,
   which is invaluable when an app suddenly misbehaves.

## Next Steps

Once the basic extract-and-install flow is familiar, Pacifist's other tricks open up. It reads a wide
range of archives — .zip, .tar, .tar.gz, .tar.bz2, .pax, .xar and more — so the same window that opens
installers also opens compressed archives, letting you grab one file from a large download without
unpacking the lot. Some archive types can even be loaded over HTTP, so you can pull a single file from
a big remote .zip without waiting for the full download to finish.

There's also a system-auditing side. pacifist mac can examine the kernel extensions installed on your
Mac and tell you which installer placed each one and whether it came from Apple or a third party —
genuinely useful when you're tracking down a mystery kext.
